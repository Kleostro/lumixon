# lumixon

## Вариант 1: Bun уже установлен

Если у вас уже установлен Bun, просто клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/your-username/lumixon.git
cd lumixon
bun install
```

Вариант 2: Bun НЕ установлен
Если у вас не установлен Bun, выполните следующие шаги в зависимости от вашей ОС.
macOS и Linux
Выполните команду установки в терминале:

```bash
curl -fsSL https://bun.com/install | bash
```

После установки перезапустите терминал или выполните команду, которую выведет установщик (обычно это добавление пути в .bashrc или .zshrc).

#### Проверка установки

Убедитесь, что Bun установился корректно:

```bash
bun --version
```

#### Установка зависимостей

После установки Bun перейдите в папку проекта и установите пакеты:

```bash
bun install
```

Примечание: Команда bun install автоматически запустит скрипт prepare, который настроит Git-хуки (Husky).

## 🛠 Скрипты проекта

Все команды запускаются через bun <название_скрипта>.

| Скрипт | Описание                  |
| ------ | ------------------------- |
| dev    | Запуск локального сервера |
| build  | Сборка проекта            |
| format | Форматирование кода       |
| lint   | Проверка кода             |
